# ADR 0007. Combat Turn Timer через Script Extender

Статус: принято.

## Контекст

Таймер должен показывать игроку остаток времени, принимать настройки из окна игры
и завершать только действующий ход управляемого им персонажа.

## Решение

Сервер на Lua сверяет участников отряда и состояние боевой инициативы, хранит настройки
в сохранении и по истечении времени вызывает штатный `EndTurn`. Клиент рисует окно IMGUI
и получает состояние от сервера. Отсчёт отдельный для каждого персонажа с действующим ходом.

## Альтернативы

Правка XAML потребовала бы переопределить общий виджет и всё равно оставила бы задачу
серверного завершения хода. Lua и IMGUI обходятся без переопределений игровых ресурсов.
