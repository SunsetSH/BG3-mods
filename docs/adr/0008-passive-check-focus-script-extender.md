# ADR 0008. Passive Check Focus через Script Extender

Статус: принято.

## Контекст

Пассивный бросок завершается на сервере. Команда движения по клику и камера принадлежат
клиенту игрока, которому назначен персонаж.

## Решение

Сервер слушает `RollResult` и отправляет запрос клиенту владельца персонажа для обоих
исходов пассивного броска. Клиент запрашивает отмену движения и наводит игровую камеру.
Оба шага используют Script Extender, игровых файлов в пакете нет.

## Альтернативы

`PurgeOsirisQueue` очищает только команды сюжета. Телепорт в текущую позицию вмешивается
в логику перемещения и может изменить положение персонажа при привязке к сетке.
