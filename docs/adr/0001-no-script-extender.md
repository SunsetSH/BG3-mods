# 0001. Мод без Script Extender

Дата: 2026-11-23. Статус: принято. Область: DC Check (с ADR 0006 каждый мод выбирает механизм сам).

## Контекст

DC можно показать двумя путями: (A) изменить только данные и UI, которые игра грузит сама: XAML виджета, локализацию, `.lsx`; (B) Lua-скрипт на BG3 Script Extender, который читает проверку в рантайме. Путь B гибче, но игроку нужен Script Extender, а такие моды нельзя ставить через встроенный менеджер модов (mod.io). У пользователя все моды стоят через mod.io, Script Extender не установлен.

## Решение

Путь A: только данные и UI, без Script Extender. Механизм внутри пути A (XAML или локализация) выбирается отдельным ADR после исследования.

## Последствия

- Мод ставится в один клик через mod.io и работает на консолях, если там разрешены такие моды (не проверено).
- Нет доступа к состоянию игры в рантайме: всё, что нужно, должно быть в статичных данных или в привязках (bindings) XAML.
- Патчи игры могут ломать оверрайды файлов: после каждого патча прогон по `mods/dc_check/TESTING.md`.
- Конфликты с UI-модами (ImpUI) и модами-переводами нужно проверять явно.
