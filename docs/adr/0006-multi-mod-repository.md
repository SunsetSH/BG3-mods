# 0006. Несколько модов в одном репозитории

Дата: 2026-11-24. Статус: принято.

## Контекст

В репозитории появился второй мод (Run Speed) и будут следующие. Код DC Check и Run Speed был перемешан: пакет `dc_check` держал и общие обёртки (Divine, lsx, meta), и пути Run Speed; версия DC Check синхронизировалась в трёх местах; `pack.py` знал каждый мод по имени. Репозиторий переименован в `SunsetSH/BG3-mods`.

## Решение

- Мод = папка `mods/<slug>/` (snake_case): `pak/Mods/<Pak>_<UUID>/` (ровно содержимое `.pak`), `README.md` с обязательным разделом «Установка», `TESTING.md`, по желанию `NOTES.md`.
- Один Python-проект `bg3-mods`, пакет `bg3_mods`: общий код в корне пакета, код конкретного мода в `bg3_mods/<slug>/`, его скрипты `scripts/<slug>_<действие>.py`.
- Источник правды о моде: его `meta.lsx`. Имя `.pak` берётся из папки модуля, версия из `Version64`. Реестр `bg3_mods/mods.py` находит моды сам, общие проверки (папка, UUID, версии, Script Extender, содержание «Установки», строка в README корня и раздел в PLAN) идут для каждого мода в `tests/test_mods.py` и в `pack.py`.
- Новый мод: `scripts/new_mod.py` создаёт заготовку; `pack.py` и тесты не пропустят шаблонный текст `ЗАПОЛНИТЬ`.
- ADR, PLAN и общие NOTES остаются в `docs/`, нумерация ADR сквозная. Механизм (без SE или с SE) каждый мод выбирает своим ADR; ADR 0001 относится к DC Check.
- Релизы по модам: тег `<slug>-vX.Y.Z`.
- Локальные сборки: `pack.py` складывает готовые `.pak` всех модов в общую папку `paks/`. Там же можно хранить готовые утилиты, необходимые для интерфейса мода. ZIP-архивы для релизов идут в `build/`.

## Альтернативы

- Отдельный репозиторий на мод: дублируются инструменты, LSLib, хуки и кэш данных игры (`unpacked/` весит гигабайты).
- uv workspace с пакетом на мод: больше конфигурации ради двух-трёх модулей на мод; можно перейти позже, если моду понадобятся свои зависимости.

## Последствия

- Добавить мод = `new_mod.py` + документы, без правки `pack.py`. Генерируемые части мода регистрируются в `mods.GENERATED`.
- Пути поменялись: `mod/` → `mods/dc_check/pak/`, `run-speed/` → `mods/run_speed/`, `scripts/generate.py` → `scripts/dc_check_generate.py`, `pack.py --mod runspeed` → `pack.py run_speed`.
