# 0005. Run Speed на Script Extender

Дата: 2026-11-23. Статус: принято. Исключение из ADR 0001 только для мода Run Speed.

## Контекст

Нужно: скорость бега отряда от 0,5x до 10x, ползунок в игре, свёрнутое окно у края экрана, в бою и пошаговом режиме обычная скорость. В статах игры нет буста, который меняет скорость передвижения вне боя (`mods/run_speed/NOTES.md`). Скорость лежит в полях шаблона персонажа (`MovementSpeedRun` и др.), а менять их на лету и рисовать своё окно умеет только Script Extender (Lua, `Ext.IMGUI`).

Альтернатива: оверрайд шаблонов с одной фиксированной скоростью. Ставится через mod.io, но без ползунка, без окна и без отключения в бою, и конфликтует с любым модом, который трогает те же шаблоны.

## Решение

Run Speed использует Lua на BG3 Script Extender с API 33. Сервер умножает поля шаблонов участников отряда, клиентам рассылает те же абсолютные значения через `Ext.Net.CreateChannel`. Окно на `Ext.IMGUI`. Механизм повторяет открытый мод FallenStar08/Configurable_Run_Speed (MIT, проверен игроками). API сверены с исходниками общедоступной сборки v33 на коммите `1fa0e10`.

## Последствия

- Игроку нужен установленный Script Extender. Через встроенный менеджер mod.io мод не заработает, распространяется вручную (Nexus, GitHub).
- Без Lua-интерпретатора логику не протестировать автоматически: `scripts/pack.py` проверяет только `Config.json` и пути `Ext.Require`, остальное по `mods/run_speed/TESTING.md`.
- Шаблон может быть общим у персонажа отряда и NPC: тогда NPC с тем же шаблоном вне боя тоже ускорятся.
- DC Check остаётся без Script Extender, ADR 0001 для него в силе.
