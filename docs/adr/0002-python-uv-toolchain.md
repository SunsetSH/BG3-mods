# 0002. Python 3.15 + uv для скриптов сборки

Дата: 2026-11-23. Статус: принято.

## Контекст

Нужны скрипты: распаковка игры, разбор `.lsx` (XML), генерация файлов мода, упаковка. Варианты: Python, C# (LSLib это .NET-библиотека, можно звать её напрямую), Node/TypeScript.

## Решение

Python 3.15.2 (последняя стабильная на дату), uv 0.13.9 для окружения, ruff 0.17.6, mypy 2.4.1 strict, pytest 9.2.0. Divine вызываем как CLI, а не как библиотеку. Внешних runtime-зависимостей нет: хватает stdlib (`xml.etree`, `zipfile`, `subprocess`).

## Альтернативы

- C# с LSLib как библиотекой: прямой доступ к `.lsf` без конвертации, но нужен .NET SDK, сборка тяжелее, а объём логики маленький.
- Node/TypeScript: нет преимуществ для работы с XML и файлами, лишний npm-граф.

## Последствия

- Новая зависимость (например, `lxml`) только с отдельным ADR: зачем, альтернативы, размер, живость.
- Скорость Python здесь не узкое место: сборка запускается вручную, данные игры разбираются один раз.
