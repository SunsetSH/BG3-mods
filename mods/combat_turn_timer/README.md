# Combat Turn Timer

Добавляет сворачиваемый таймер хода в Baldur’s Gate 3. Пока у управляемого персонажа есть действующий ход в бою, таймер считает время до его автоматического завершения.

## Возможности

- Лимит от 5 до 300 секунд, по умолчанию 60. Передвиньте ползунок и нажмите «Применить». Новый лимит действует со следующего хода, настройка хранится в сохранении отдельно для каждого профиля игрока.
- Окно находится слева, его можно перетащить и свернуть стрелкой в заголовке. При вступлении в бой окно разворачивается, даже если инициатива принадлежит противнику.
- Цифры и полоска меняют цвет с зелёного через янтарный на красный. При общей инициативе у каждого персонажа отряда свой отсчёт. Окно показывает ближайший тайм-аут и число активных ходов.
- Таймер останавливается при выходе игры из состояния обычного игрового процесса. Загруженный посреди боя ход получает полный лимит.
- Окно на русском или английском по языку игры. Отдельный пошаговый режим вне боя проходит без отсчёта.

## Установка

1. Установить BG3 Script Extender с API 33 или новее. Скачать `BG3SE-Updater-20261012.zip` со страницы [Norbyte/bg3se v33](https://github.com/Norbyte/bg3se/releases/tag/v33). Имя архива и путь установки сверены 25.11.2026.
2. Из архива распаковать `DWrite.dll` в папку `bin` игры. Стандартный путь Steam `C:\Program Files (x86)\Steam\steamapps\common\Baldurs Gate 3\bin`. Для другой библиотеки открыть Steam → ПКМ по игре → «Управление» → «Просмотреть локальные файлы» → `bin`.
3. Скачать `CombatTurnTimer.pak` в разделе **Assets** [общего релиза `mods-2026-11-25`](https://github.com/SunsetSH/BG3-mods/releases/tag/mods-2026-11-25). Если скачали `CombatTurnTimer-0.1.0.zip`, извлечь из него `CombatTurnTimer.pak`.
4. Положить `CombatTurnTimer.pak` в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`. В главном меню открыть «Моды» → «Установленные» и включить «Combat Turn Timer».
5. Удаление. Выключить мод в менеджере, закрыть игру и удалить `CombatTurnTimer.pak`. Оставить `DWrite.dll`, если он нужен другим модам.

## Совместимость

- Версия 0.1.0 доступна для пробного использования на Windows с мышью. Ручная проверка в игре ещё впереди, в том числе для кооператива и геймпада.
- Охватывает персонажей из `DB_PartyMembers`, назначенных игроку. Призывы и временные существа вне этой базы проходят бой по обычным правилам.
- Моды, которые меняют порядок инициативы или сами завершают ход, могут влиять на момент срабатывания.
- В сохранении хранятся только настройки Lua. Загрузка без мода входит в ручную проверку.

## Сборка

~~~sh
uv run python scripts/pack.py combat_turn_timer
~~~

Сборщик создаёт `paks/CombatTurnTimer.pak` и `build/CombatTurnTimer-0.1.0.zip`.

## Устройство

| Файл в `pak/Mods/CombatTurnTimer_<UUID>/` | Назначение |
|---|---|
| `meta.lsx` | Имя, UUID и версия |
| `ScriptExtender/Config.json` | Настройки загрузки Script Extender |
| `ScriptExtender/Lua/Bootstrap{Server,Client}.lua` | Входы серверного и клиентского Lua |
| `ScriptExtender/Lua/Shared/Timer.lua` | Диапазон, значение по умолчанию и сетевые каналы |
| `ScriptExtender/Lua/Server/Timer.lua` | Лимиты профилей, отсчёт и завершение ходов |
| `ScriptExtender/Lua/Client/Window.lua` | Окно, настройки и цвет остатка времени |
