# Ручная проверка Run Speed в игре

Автоматически Lua не проверить, поэтому перед «готово» пройдите список и запишите результат. Что не проверено, пишите прямо.

1. `uv run python scripts/pack.py run_speed`, затем установить Script Extender и `paks/RunSpeed.pak` строго по разделу «Установка» в [README.md](README.md).
2. Загрузить сохранение. У правого края экрана, примерно на трети высоты, есть окно «Скорость бега» с ползунком, кнопками `1x 2x 3x 5x 10x` и подсказкой. В консоли SE (F10 при включённой консоли) нет красных ошибок от `RunSpeed`.
3. Окно сворачивается стрелкой в заголовке и разворачивается обратно, перетаскивается мышью.
4. Кнопка `2x`: персонаж и спутники бегут заметно быстрее, спутники не отстают. `10x` и `0.5x`: быстро и медленно, без провалов сквозь пол и рывков назад.
5. Ползунок: при перетаскивании меняется подпись, скорость меняется после отпускания мыши.
6. Начать бой: в бою скорость обычная. После боя снова выбранная.
7. Пошаговый режим вне боя (кнопка с песочными часами): скорость обычная, после выхода снова выбранная.
8. Сохранить, выйти в меню, загрузить: значение на ползунке то же, скорость та же, и не выросла вдвое (проверка на повторное умножение).
9. Загрузить другое сохранение без выхода из игры: скорость там своя (1x, если мод там не настраивался).
10. Язык игры русский и английский: заголовок и подсказка на языке игры, кириллица читается.
11. Новый спутник присоединился к отряду: тоже ускорен. Спутник ушёл из отряда: обычная скорость.
12. Дикий облик друида и превращения: записать, что происходит со скоростью (ожидается: обычная скорость облика).
13. Выключить мод и загрузить сохранение, сделанное с ним: скорость обычная, сохранение грузится.
