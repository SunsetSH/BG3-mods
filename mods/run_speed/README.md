# Run Speed

Мод для Baldur's Gate 3: скорость бега отряда вне боя от 0,5x до 10x. Значение задаётся ползунком в маленьком окне у правого края экрана, окно сворачивается. В бою и пошаговом режиме скорость обычная. Значение хранится в сохранении.

## Возможности

- Ползунок от 0,5x до 10x и кнопки `1x 2x 3x 5x 10x` в сворачиваемом окне, окно можно перетаскивать.
- Ускоряются все участники отряда, спутники не отстают.
- В бою и пошаговом режиме скорость обычная, после выхода снова выбранная.
- Подписи окна на русском и английском, по языку игры.

## Установка

Для Run Speed нужен BG3 Script Extender с API 33 или новее.

1. Скачать `BG3SE-Updater-20261012.zip` со страницы [Norbyte/bg3se v33](https://github.com/Norbyte/bg3se/releases/tag/v33). Имя архива и путь установки сверены 25.11.2026. Загрузчик обновляет Script Extender при запуске игры с доступом к интернету.
2. Распаковать из архива `DWrite.dll` в папку `bin` игры. Путь Steam по умолчанию `C:\Program Files (x86)\Steam\steamapps\common\Baldurs Gate 3\bin`. В Steam папку можно открыть через ПКМ по игре → «Управление» → «Просмотреть локальные файлы» → `bin`.
3. Скачать `RunSpeed.pak` в разделе **Assets** [общего релиза `mods-2026-11-25`](https://github.com/SunsetSH/BG3-mods/releases/tag/mods-2026-11-25). Если скачали `RunSpeed-1.0.0.zip`, извлечь из него `RunSpeed.pak`.
4. Положить `RunSpeed.pak` в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods` (вставить путь в адресную строку Проводника).
5. В игре открыть «Моды» → «Установленные» и включить «Run Speed».
6. Удаление. Выключить мод в менеджере, закрыть игру и удалить `RunSpeed.pak`. Если Script Extender нужен другим модам, оставить `DWrite.dll` в папке `bin`.

## Совместимость

- Моды, которые меняют поля скорости в шаблонах персонажей (`MovementSpeedRun` и др.), могут конфликтовать: не проверено.
- NPC с тем же шаблоном, что у участника отряда, вне боя тоже ускоряются (ADR 0005).
- Сохранение без мода грузится, скорость обычная.

## Сборка

```sh
uv run python scripts/pack.py run_speed   # paks/RunSpeed.pak и build/RunSpeed-<версия>.zip
```

## Устройство

| Файл в `pak/Mods/RunSpeed_<UUID>/` | Что делает |
|---|---|
| `meta.lsx` | имя, UUID, версия мода |
| `ScriptExtender/Config.json` | версия API Script Extender, имя таблицы мода |
| `ScriptExtender/Lua/Shared/Speed.lua` | пределы множителя, поля шаблона, сетевые каналы |
| `ScriptExtender/Lua/Server/Speed.lua` | меняет шаблоны отряда, следит за боем и пошаговым режимом, откатывает перед сохранением |
| `ScriptExtender/Lua/Client/Window.lua` | окно с ползунком, применяет значения на клиенте |

Почему так: [ADR 0005](../../docs/adr/0005-run-speed-script-extender.md). Нюансы: [NOTES.md](NOTES.md). Проверка в игре: [TESTING.md](TESTING.md).
