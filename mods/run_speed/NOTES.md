# Нюансы: Run Speed

Данные ниже проверены на игре с Patch 8 Hotfix 10 (последний `Patch8_HotFix10.pak` в `Data`), LSLib v1.20.4, 2026-11-23.

## Script Extender

- **Минимальная версия API 33.** На 25.11.2026 загрузчик устанавливает v33 из канала Release, исходники сборки на коммите `1fa0e10`. В этой версии есть используемые модом IMGUI, сетевые каналы и доступ к шаблонам. Значение `RequiredVersion` выше установленной версии вызывает предупреждение при запуске. [Исходники обработки Config.json](https://github.com/Norbyte/bg3se/blob/1fa0e10eefba50941483328dc0c26a62047cc5c7/BG3Extender/Extender/Shared/ExtensionState.cpp)
- **Шаблоны переживают загрузку сохранения.** Шаблоны персонажей живут весь процесс игры, а Lua-состояние SE создаётся заново на каждую сессию. Если не откатить изменённые поля, следующая загрузка запомнит ускоренные значения как исходные и умножит ещё раз. Поэтому сервер откатывает всё при любом выходе из состояния `Running` (сохранение, пауза, выгрузка) и применяет заново при входе. Исходники bg3se, коммит `6082eed`.
- **SE: объекты движка нельзя хранить между вызовами.** Ссылка на шаблон или компонент истекает после обработчика («lifetime has expired»). Run Speed хранит только id шаблонов и GUID персонажей и каждый раз берёт `Ext.Entity.Get(guid).ServerCharacter.Template` заново.
- **Скорость статами не меняется**: в статах игры нет буста, который меняет скорость передвижения вне боя, поэтому нужен Script Extender (ADR 0005).
