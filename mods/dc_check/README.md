# DC Check

Мод для Baldur's Gate 3: показывает сложность проверки (DC, «КС») прямо в варианте ответа диалога, до того как вы его выбрали. Сейчас игра показывает только навык («[Убеждение]»), а число вы видите уже на экране броска. Бонус персонажа к броску игра и так показывает при наведении, мод его не трогает.

Мод работает без Script Extender. После копирования `.pak` его можно включить во встроенном менеджере модов. Поддерживаются русский и английский языки игры.

## Возможности

- В варианте ответа с проверкой перед текстом стоит DC: `[УБЕЖДЕНИЕ] (КС 15) <текст варианта>`, в английской игре `[PERSUASION] (DC 15) <option text>`. Число берётся из той же таблицы, что и экран броска, поэтому учитывает акт.
- Работает для навыков, характеристик и спасбросков. Атаки и броски против существа без фиксированного DC не помечаются.
- Если один текст встречается в проверках с разными DC, показываются оба: `(DC 5/10)`.
- Русский текст учитывает пол героя: женские формы реплик тоже с КС.
- Другие языки игры не меняются.

## Установка

Дополнительные утилиты не нужны: ни Script Extender, ни менеджеры модов.

1. Скачать `DCCheck.pak` в разделе **Assets** [общего релиза `mods-2026-11-25`](https://github.com/SunsetSH/BG3-mods/releases/tag/mods-2026-11-25). Если скачали `DCCheck-1.0.0.zip`, извлечь из него `DCCheck.pak`.
2. Положить `DCCheck.pak` в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods` (вставить путь в адресную строку Проводника).
3. В игре открыть «Моды» → «Установленные» и включить «DC Check». Если стоит мод-перевод (например, Fixed Russian translation), поставить DC Check ниже него в порядке загрузки.
4. Удаление: выключить мод в менеджере модов и удалить `DCCheck.pak`.

Мод меняет только тексты, сохранения от него не зависят.

## Совместимость

- UI-моды (ImpUI, BetterTooltips и другие) не мешают: мод не трогает XAML.
- Моды-переводы меняют те же строки. Побеждает мод ниже в списке. Чтобы сохранить правки перевода, соберите личную версию: `uv run python scripts/dc_check_generate.py --base-pak <путь к .pak перевода>`, затем `uv run python scripts/pack.py dc_check`.
- После патча игры, который меняет диалоги, нужна пересборка: `dc_check_generate.py --refresh`.

## Сборка

```sh
uv run python scripts/dc_check_generate.py   # локализация из данных игры (~30 с, кэш в unpacked/)
uv run python scripts/pack.py dc_check       # paks/DCCheck.pak и build/DCCheck-<версия>.zip
```

## Устройство

| Путь | Что делает |
|---|---|
| `pak/Mods/DCCheck_<UUID>/meta.lsx` | имя, UUID, версия мода |
| `pak/Mods/DCCheck_<UUID>/Localization/` | генерируется `dc_check_generate.py`, вне git (текст Larian) |
| `src/bg3_mods/dc_check/sources.py` | какие паки и файлы игры нужны генератору, куда писать локализацию |
| `src/bg3_mods/dc_check/difficulty.py` | таблица DC: UUID → число |
| `src/bg3_mods/dc_check/dialogs.py` | узлы `ActiveRoll` из диалогов |
| `src/bg3_mods/dc_check/labels.py` | метка `(DC 15)` и какие тексты её получают |
| `scripts/dc_check_generate.py` | распаковка данных игры и генерация локализации |
