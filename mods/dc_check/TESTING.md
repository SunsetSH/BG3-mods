# Ручная проверка DC Check в игре

Автоматически игру не запустить, поэтому перед «готово» по изменениям, которые видит игрок, пройдите этот список и запишите результат в ответ.

1. `uv run python scripts/dc_check_generate.py`, `uv run python scripts/pack.py dc_check`, затем установить `paks/DCCheck.pak` строго по разделу «Установка» в [README.md](README.md). Мод грузить после модов-переводов (ниже в списке).
2. Загрузить сохранение рядом с диалогом с проверкой навыка. В варианте ответа видно `(КС 10) ...` сразу после тега навыка, и число совпадает с КС на экране броска. Пример из пролога: пожиратель разума в лаборатории «Наутилоида» (`TUT_Lab_TrappedDevourer`): «Расколоть череп.» КС 10, «Искалечить мозг.» КС 15.
3. То же на английском и русском языке игры (`(DC 10)`).
4. Вариант без проверки: текст не изменился.
5. Проверка в другом акте: КС соответствует таблице этого акта (например, акт 2: Medium = 14).
6. Русский, героиня (женский персонаж): у вариантов с женскими формами («я сделала») тоже есть КС. Это проверка гендерных файлов `Gender/Female/`.
7. Вариант-атака или проверка с броском против существа: метки нет, игра работает как раньше.
8. С включёнными ImpUI и BetterTooltips: диалог открывается, подсказка с бонусом при наведении на тег навыка на месте.
9. С Fixed Russian translation: если DC Check ниже в списке, КС видно. Личная сборка с `--base-pak` сохраняет правки перевода (например, «её» вместо «ее»).
10. Выключить мод: диалоги выглядят как в оригинале, сохранение грузится.

Что не удалось проверить, пишите прямо: «пункт 5 не проверен, нет сохранения во 2 акте».
