# Passive Check Focus

Помогает заметить пассивные проверки в Baldur’s Gate 3. После броска мод запрашивает отмену движения по клику и наводит камеру на персонажа, у которого сработала проверка. Успех и провал обрабатываются одинаково.

## Возможности

- Реагирует на пассивные броски персонажей, назначенных игроку, включая проверки внимания, которые игра передаёт через `RollResult`.
- Отправляет отмену активного движения по клику персонажу, сделавшему бросок. Если он идёт в связанной группе за выбранным персонажем, мод также отменяет движение по клику у лидера.
- Выбирает персонажа, сделавшего бросок, и центрирует на нём камеру владельца. Если несколько персонажей одного игрока бросили в одном тике, цель камеры выбирается по первому броску.
- Активные броски, диалоговые проверки и броски заклинаний без события `RollResult` идут своим обычным ходом.

## Установка

1. Установить BG3 Script Extender с API 33 или новее. Скачать `BG3SE-Updater-20261012.zip` со страницы [Norbyte/bg3se v33](https://github.com/Norbyte/bg3se/releases/tag/v33). Имя архива и путь установки сверены 25.11.2026.
2. Из архива распаковать `DWrite.dll` в папку `bin` игры. Стандартный путь Steam `C:\Program Files (x86)\Steam\steamapps\common\Baldurs Gate 3\bin`. Для другой библиотеки открыть Steam → ПКМ по игре → «Управление» → «Просмотреть локальные файлы» → `bin`.
3. Скачать `PassiveCheckFocus.pak` в разделе **Assets** [общего релиза `mods-2026-11-25`](https://github.com/SunsetSH/BG3-mods/releases/tag/mods-2026-11-25). Если скачали `PassiveCheckFocus-0.1.0.zip`, извлечь из него `PassiveCheckFocus.pak`.
4. Положить `PassiveCheckFocus.pak` в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`. В главном меню открыть «Моды» → «Установленные» и включить «Passive Check Focus».
5. Удаление. Выключить мод в менеджере, закрыть игру и удалить `PassiveCheckFocus.pak`. Оставить `DWrite.dll`, если он нужен другим модам.

## Совместимость

- Версия 0.1.0 доступна для пробного использования на Windows с движением по клику. Удержание стика, WASD из сторонних модов и сюжетные команды движения используют другие механизмы. Ручная проверка в игре ещё впереди, в том числе для кооператива и разделённого экрана.
- Центрирование опирается на команду штатного интерфейса. Моды, которые заменяют панели интерфейса, меняют выбор персонажей или управляют камерой, могут влиять на результат.
- Мод не добавляет игровых сущностей и постоянных данных в сохранение. Загрузка без мода входит в ручную проверку.

## Сборка

~~~sh
uv run python scripts/pack.py passive_check_focus
~~~

Сборщик создаёт `paks/PassiveCheckFocus.pak` и `build/PassiveCheckFocus-0.1.0.zip`.

## Устройство

| Файл в `pak/Mods/PassiveCheckFocus_<UUID>/` | Назначение |
|---|---|
| `meta.lsx` | Имя, UUID и версия |
| `ScriptExtender/Config.json` | Настройки загрузки Script Extender |
| `ScriptExtender/Lua/Bootstrap{Server,Client}.lua` | Входы серверного и клиентского Lua |
| `ScriptExtender/Lua/Shared/Channel.lua` | Каналы отмены движения и камеры |
| `ScriptExtender/Lua/Server/Checks.lua` | Фильтр бросков, назначенный игрок и цель камеры |
| `ScriptExtender/Lua/Client/Focus.lua` | Запрос отмены движения и команда камеры из игрового интерфейса |
